Only One Switch

A dial that tells a machine where it is. Each ring is a switch, read by a little contact. The contacts are never perfectly lined up. Watch what the machine reads as the dial turns.

dial is at0
machine reads0

The rule: neighbouring positions may differ in only one switch.

Why only one

Count in ordinary binary and some steps flip lots of switches at once. Going from 7 to 8 on four switches, all four change: 0111 to 1000. Real switches never flip at exactly the same instant. So for a moment, halfway through the step, the machine can read a mix of old and new switches: 15, or 0, or 12. Those numbers are nowhere near where the dial actually is.

The fix is a different order for the numbers, in which each step changes just one switch. Then a reading caught mid-step can only be the old position or the new one. Never anywhere else. Try both codes above with the contacts set sloppy, and count the impossible readings.

Frank Gray, at Bell Labs, wrote it down in a 1947 patent application for turning sound into pulses with a vacuum tube. He called it the reflected binary code and said it had "as yet no recognized name". The patent was granted in 1953, and everyone else started calling it Gray code.

He wasn't first. In the 1870s the French telegraph engineer Émile Baudot ordered the letters on his printing wheel in the same way. Louis Gros described the same order in 1872, as the solution to an old puzzle called the Chinese rings.

The "reflected" part is how you build it. Write the list for one switch: 0, 1. Then write it again backwards, as if in a mirror, and put a 1 in front of the mirrored half: 00, 01, 11, 10. Mirror again for three switches, and so on. Each ring on the disc is the same mirror trick at a bigger size, which is why the pattern looks the way it does.

My own note: the bells in exhibit 03 have a cousin of this rule. Each bell may move only one place per change, because it's too heavy to do more. Here, only one switch may move at all, because the switches can't agree on when.
