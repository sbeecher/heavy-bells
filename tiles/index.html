Coin-flip tiles

Type anything. Your words become a seed. The seed picks one of three old tiles, decides how far to weight the coin, then flips it for each of the 256 squares (twice for the triangles, which can face four ways).

Same flips, another tile:

Same words, same pattern, every time. Change one letter and the whole picture reshuffles, and often changes tile too.

The rule: every square holds the same tile. Flip a coin to decide which way it faces. Nothing else. The tile can be two quarter-circles (Smith, 1987), a square cut into a dark and a light triangle (Truchet, 1704; these have four ways to face, so it takes two flips), or one diagonal line (the maze).

The maze is the famous one in computing: 10 PRINT CHR$(205.5+RND(1)); : GOTO 10, a one-line program for the Commodore 64 that prints a random ╱ or ╲ forever. Nick Montfort and nine co-authors wrote a whole book about that one line.

Cyril Stanley Smith wrote about it in 1987 and made it famous, but Wikipedia says the board games Trax and the Black Path Game used the same tile before him.
